# 치앙마이, 나의 속도로 — 모바일 여행 UI 개편

확인일: 2026-11-23. 기존 `/travel`의 데이터·비공개 접근·자동 저장을 유지한다.

## 진단과 적용

| 기존 문제 | 적용한 변화 | 사용자가 바로 하는 일 |
| --- | --- | --- |
| 예약, 장소, 코스, 달력이 모두 홈에서 경쟁 | 하루 일정 중심 홈, 예약은 작은 바로가기 | 오늘의 오전·오후·저녁 확인 |
| 글자 굵기와 큰 초록 패널이 반복 | SUITE Variable, 중간 굵기, 밝은 바탕·블루·소량의 코랄, 일관된 선 아이콘 | 긴 메모보다 제목과 다음 행동을 먼저 읽기 |
| 사진 없는 장소도 빈 이미지 영역 차지 | 작은 사진/아이콘의 장소 목록, 펼치면 상세 | 이름·동네로 빠르게 식당 찾기 |
| 코스와 날짜가 분리 | 코스 상세에서 날짜를 골라 연결, 실제 주행 기록도 선택 가능 | 선택한 날의 오전에 코스 표시 |
| 여행 경험을 추가해도 별도 메모가 필요 | 발견 카드의 ‘일정에 담기’ | 기존 일정 텍스트를 보존하며 경험 추가 |
| 본 적 있는 추천과 휴관일이 계속 노출 | 이미 아는 곳·다녀옴 저장, 요일/휴관일/당일 종료시각 필터 | 새 후보에 집중 |
| 리커버리는 이름에 Easy/Recovery가 있는 기록만 | 실제 주행 강도는 유지하고 검증된 평지 회복 코스 2개 보강 | 회복일에 바로 고를 선택지 확보 |

하단 메뉴: 오늘 / 일정 / 코스 / 발견 / 더보기. 예약·준비물·저장한 식당은 홈 바로가기와 더보기에 유지한다. 월간 캘린더는 일정 화면에서 펼쳐 본다. 코스 목록의 세 열(이름·거리·획득고도)은 유지한다.

## 벤치마킹

인기 순위 1위라고 단정하지 않고 여행 계획의 대표적인 세 제품에서 검증 가능한 패턴을 선택했다.

- **Wanderlog**: 날짜별 일정과 장소·지도를 함께 구성. 이번에는 일정에 코스/발견 연결, 개별 지도·길찾기를 적용했다. 전체 경로 최적화·실시간 이동시간 계산은 구현하지 않았다.
  - https://wanderlog.com/plan-a-trip
  - https://help.wanderlog.com/hc/en-us/articles/13545624787867-Optimize-route
- **TripIt**: 필요한 시점의 일정과 예약에 접근. 홈을 하루 중심으로 바꾸고 항공·호텔 정보는 한 번에 열도록 했다. 항공편 실시간 추적 기능을 추가한 것은 아니다.
  - https://www.tripit.com/web/free
- **Polarsteps**: 여행 취향에 맞는 발견 이유와 계획·기록 연결. ‘왜 이 날짜에 어울리는지’, 가보고 싶은 곳/다녀온 곳을 분리했다. AI나 위치추적을 사용한다고 표시하지 않는다.
  - https://www.polarsteps.com/travel-planner
- **서체**: 제작자 공식 배포 SUITE Variable. 원격 글꼴이 로드되지 않으면 운영체제 한글 글꼴로 표시한다. CSP에는 폰트/스타일의 고정 CDN 호스트만 추가하고 외부 스크립트는 허용하지 않는다.
  - https://sun.fo/suite/

‘새로 생긴 경험’과 ‘새롭게 알아볼 장소’를 구분한다. 사용자가 과거에 방문하지 않았다는 사실은 알 수 없으므로 미방문으로 단정하지 않는다.

소요시간은 편집 제안이다. 운영시간은 위 확인일 기준이며 실시간 영업 상태·임시휴무·미래 전시를 보장하지 않는다. 정기 휴무와 확인된 연초 휴관일은 날짜 선택에서 차단하고 당일 종료시각이 지났으면 추천에서 제외한다. 알려진 장소는 홈 추천에서 제외하며 발견 탭의 ‘이미 만난 곳’에서 확인/변경한다.

사진은 해당 운영사의 공식 소개 페이지 이미지를 사용하고 카드 상세에 출처를 표시한다. 이미지가 로드되지 않아도 제목·정보·행동은 사용 가능하다.

## 리커버리 수정

거리만 보고 실제 주행의 강도를 회복이라고 재해석하지 않는다. 짧은 도이수텝과 55 그룹라이드 기록은 유지한다. 평소 중장거리 라이딩과 대비해 **낮은 강도로 선택할 수 있는 코스**를 리커버리 목록에 보강한다.

- 후아이퉁타오 호수 왕복: 참고 경로 34km / 획득고도 100m 미만. 수텝 로드 출발 경로이며 숙소 출발 거리로 단정하지 않는다. [실주행자의 가이드·GPX](https://gobackpackgo.com/huay-tung-tao-cycling/)
- 핑강 북쪽 루프: 가이드 범위 55–75km / 약 55m. 단축 가능한 평지 소셜 코스. 범위를 확정 단일 수치처럼 표시하지 않는다. [현지 라이더 가이드·GPX](https://chiangmaicyclist.wordpress.com/2023/11/06/ride-of-the-week-northern-river-loop/)

추가는 로그인 후 기존 자동 저장으로 한 번만 적용한다. 사용자가 나중에 수정한 내용은 다시 덮어쓰지 않는다.

## 검증 범위와 후속 우선순위

자동 검증: 기존 인증·저장·충돌 회귀, 범위 수치 표시, 원래 기록 보존, 회복 코스 중복 추가 방지, 휴관/요일/당일 종료, 이미 아는 곳 제외, 발견 일정 저장·재접속, 실제 코스 연결, HTML 이스케이프.

직접 연결된 브라우저가 없어 iPhone 실기기 화면은 이번 작업에서 관찰하지 못했다. 기존 서버 인증과 자동 저장 검증은 유지한다.

후속 개선 우선순위:
1. 실제 위치가 확인된 식당·발견을 한 지도에 묶고 날짜별 동선 비교.
2. 실제 기기에서 엄지 동선, 320–430px 화면 줄바꿈, 확대 글꼴 확인.
3. 사용자가 남긴 방문 취향으로 추천 가중치를 조정. 실시간 AI나 이동시간 계산은 별도 기능으로 검증 후 도입.
