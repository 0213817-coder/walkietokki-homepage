# 웹과 설치형 앱: 나의 속도로

주소: https://walkietokki.com/ridebook/

동일한 GitHub 소스에서 생성하는 웹 + 홈 화면 설치형 PWA입니다. App Store 네이티브 앱은 아닙니다.

## 처음 사용

1. 새 주소에서 **기존 사이트에서 옮기기**를 선택합니다.
2. 기존 비공개 사이트에 로그인하고 **앱으로 옮기기**를 누릅니다.
3. 새 앱의 **이 여행 가져오기**를 눌러 기기에 저장합니다.
4. 또는 기존 사이트의 데이터 백업 JSON을 새 앱에서 가져옵니다.
5. 휴대폰에서 앱을 설치한 뒤 여행이 보이지 않으면, 설치된 앱에서 같은 백업을 한 번 가져옵니다. 브라우저/설치 앱의 저장 공간 분리는 운영체제와 브라우저에 따라 다릅니다.

iPhone: Safari → 공유 → 홈 화면에 추가. Android: Chrome 메뉴 → 앱 설치 / 홈 화면에 추가. 설치 앱에서 **오프라인 준비 완료**를 확인하세요.

## 저장과 업데이트

- 일정·코스·예약·메모는 해당 기기의 IndexedDB에 자동 저장됩니다. 서버 로그인 없이 읽기/편집/저장이 가능합니다.
- 저장 트랜잭션 완료 후에만 ‘기기 저장 완료’로 표시합니다. 저장 실패 시 초안을 보관하고 백업/재시도를 제공합니다.
- 같은 기기의 여러 창에서 수정하면 버전을 비교하고, 서로 다른 항목은 병합합니다. 같은 항목은 사용자가 선택합니다.
- **기기 간 자동 동기화는 없습니다.** 다른 기기 또는 별도 브라우저에는 백업 파일을 가져오세요. 이 앱에서 바꾼 내용은 이전 `/travel` 서버로 돌아가지 않습니다.
- 브라우저 데이터를 삭제하거나 기기를 교체하기 전에는 앱 메뉴에서 여행 백업을 저장하세요. 운영체제가 웹 저장 공간을 회수할 가능성이 있으므로 중요한 변경 후에도 백업을 권장합니다.
- 최초 온라인 실행 후 앱 화면을 캐시합니다. 저장된 일정/메모/코스 정보와 GPX는 오프라인에서도 열립니다. 지도·외부 사진·Strava는 인터넷이 필요합니다.
- GitHub의 `node scripts/build-travel.mjs`가 기존 비공개 UI와 `/ridebook/` 정적 앱을 함께 생성합니다. 커밋에는 생성물도 포함합니다.
- 앱 업데이트를 발견하면 상단에 표시됩니다. **앱 → 새 버전 적용**을 누르면 저장을 확인한 뒤 새 캐시로 전환합니다. 개인 데이터는 캐시와 다른 저장소에 유지됩니다.

## 개인정보 경계

공개 배포물에는 개인 예약·주행·메모 초기 데이터가 없습니다. 기존 `/travel`과 `/travel/api/state`는 Cloudflare Access 및 서버 권한 검사를 유지합니다. 새 앱은 이 API를 자동 호출하지 않습니다. 서버 데이터를 공개 캐시에 넣거나 인증을 우회하지 않습니다. 기존 사이트에서 사용자가 시작한 이동만 같은 출처의 임시 저장소를 거치며, 가져오기 저장이 성공한 뒤 임시 이동 데이터를 지웁니다.

## 검증

`node scripts/build-travel.mjs` 다음 `node --test tests/*.test.mjs`.
기존 인증·서버 동기화 테스트와 함께 새 로컬 저장, 실패 복원, 동시 수정, 가져오기 도중 저장, 오프라인 캐시 및 업데이트 전환을 검증합니다.
